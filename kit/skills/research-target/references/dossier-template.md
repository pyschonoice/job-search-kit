# Dossier template

Save as `outreach/<company-slug>_<person-first-name>/research.md`. Every bullet ends with its source and date: `([src](url), 2026-10-06)`.

```markdown
# <Company> / <Person>

Purpose: cold | posting <link> | interview
Researched: <YYYY-MM-DD>
Red flags: none | <one line, e.g. "AmbitionBox 2.9 on 40 reviews, salary delays mentioned 6x (2026)">

## To
- Name: <Full Name>, <title> (since <MM/YYYY>)
- Email: <address> (published | pattern | guess) — <where it came from>
- LinkedIn: <url>
- Shared ground with the user: <college / company / tool / city / none>

## Company in 3 lines
- What they sell, to whom: ...
- How it works technically: ...
- Stage: <founded, batch, last round + date, team size>

## Recent (last 90 days)
- <launch / post / hire / round> (src, date)
- ...

## Open roles that fit
- <title> — <link> — <years asked, stack>

## Person
- Career: <prev role @ company (years)> → <...>
- Recent posts or talks: <one line each, with the angle they care about> (src, date)
- What they seem to care about: <one line, inferred from the above; say so if it's thin>

## Hooks (best first)
1. <specific thing> → bridge: <the user's matching work, with its number from my-profile>
2. ...
3. ...

## Try-it note (optional)
<what the user could try in 10 minutes: demo number, sandbox, API>

## Reviews (the user only, never in an email)
- Glassdoor: <rating, count, themes> (src)
- AmbitionBox: <rating, count, themes> (src)

## Interview prep (purpose = interview only)
- Likely topics: ...
```
